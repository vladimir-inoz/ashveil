# Ashveil

Оригинальный прототип научно-фантастического воздушного боя на Unity.

Действие: колония **Kessara**, 2419 год. Курсант Конкорда пилотирует скиф **AX-7 «Wisp»** против клана Тарн.

## Управление

- мышь — тангаж и рысканье
- W/S — газ
- A/D — крен
- Q/E — стрейф
- R/F — вертикаль
- ЛКМ / пробел — огонь
- Esc — пауза

Откройте проект в Unity 6 (6000.3 LTS) и запустите сцену `Assets/Scenes/Boot.unity`.
